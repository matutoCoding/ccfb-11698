# 手术无影灯配光与术野阴影仿真系统

浏览器端的手术无影灯配光设计、术野照度分析与遮挡阴影仿真工具。TypeScript + three.js + Vite。

## 设计原则：计算与渲染分离

系统分成两个完全独立的层：

| 层 | 技术 | 职责 |
|---|---|---|
| **物理引擎** `src/physics/` | 纯 TypeScript，零依赖、零 DOM | 照度、光斑、遮挡、深度衰减的全部数值计算 |
| **可视化层** `src/three/` | three.js | 灯头/房间/遮挡体 3D 展示、多光源软阴影（仅视觉） |

**所有分析结论（中心照度、d10/d50、残余照度比例、CSV 数据）只来自物理引擎的解析公式，three.js 不参与任何数值。** 3D 场景里的虚拟聚光灯 + PCFSoft 阴影是对"多光源叠加软阴影"的视觉近似，与解析引擎的硬判定互为独立，避免渲染近似污染测量数据。

## 物理模型与公式

### 1. 单颗 LED 照度（点光源余弦定律）

```
E = I(θ) · cos i / r²
```

- `r`：LED 发光中心到测点距离 (m)
- `θ`：LED 发光轴与光线方向夹角
- `i`：光线与受光面法线（水平面 +Y）夹角，水平面 `cos i = -rayDir.y`
- `I(θ)`：该方向光强 (cd)

### 2. 角分布与通量守恒

光强角分布按 LED 总光通量 Φ（= 功率 W × 光效 lm/W）归一化，保证总通量守恒：

| 模型 | 形状 f(θ) | 归一化系数 K（I = Φ/K·f） |
|---|---|---|
| cos^n（默认） | cosⁿθ（前向半球） | K = 2π/(n+1) |
| 朗伯 | cosθ | K = π |
| 均匀锥 | 锥内 1 / 锥外 0 | K = 2π(1-cos α) |

由 `Φ = ∫I dΩ = 2π∫I(θ)sinθ dθ` 解析得到，单元测试以 20 万步数值积分验证误差 < 0.1%。

### 3. 多光源叠加

照度满足线性可加性，总照度 = 各 LED 贡献直接求和。双灯头即两套 LED 集合合并。

### 4. 遮挡（确定性解析求交，无采样/无迭代）

对每颗 LED 与测点连成的线段做闭式求交：

- **球（医生头部）**：线段到球心最近点距离 ≤ r
- **胶囊（手/前臂）**：两线段（光线段、胶囊轴段）最近距离 ≤ r，统一处理圆柱段与两端球冠，采用 Ericson《Real-Time Collision Detection》5.1.9 解析公式

被遮挡 LED 的照度贡献记 0。逐 LED 的 r、θ、i、I、E、遮挡状态全部可在界面查看并导出 CSV，与手算逐项对应。

### 5. 光斑直径（标准口径）

- 中心照度 Ec：术野中心网格点
- **d10**：72 条径向射线寻找照度穿过 Ec/10 的位置，线性插值定位交叉点，各射线半径平均 ×2 得等效圆直径
- **d50**：阈值改为 Ec/2
- 均匀度：Emin / Emean

### 6. 深度衰减

沿不同术野平面高度计算中心照度。轴上单灯垂直照射严格服从逆平方律 E∝1/d²；环形灯因 θ 随距离变化，是逆平方律与角分布的叠加结果。

## 页面与功能

| 页面 | 功能 |
|---|---|
| 方案列表 | 方案增删改/复制、卡片摘要（Ec、d10、LED 数）、JSON 导入导出 |
| 灯头设计 | 双灯头；环形 LED 排布；逐颗倾角/功率；灯头位姿（数值+3D 拖拽 TransformControls）；角分布模型与参数 |
| 手术室布置 | 术野平面高度/区域/网格精度、房间尺寸、灯头速览 |
| 照度分析 | N×N 照度网格、热力图+d10/d50 等照度线、Ec 等 8 项指标、深度衰减曲线、CSV 报告 |
| 阴影测试 | 球/胶囊遮挡体（3D 拖拽）、残余照度比例、分灯头统计、遮挡前后热力图对比、逐 LED 明细表 |
| 设置 | 方案信息、浏览器内一键计算自检、数据管理、计算口径说明 |

方案自动保存到 `localStorage`（400ms 防抖），导出 JSON 带版本号与导入校验。CSV 为 UTF-8 BOM，Excel 直接打开中文不乱码，含 6 个分节（配置/照度/遮挡/逐 LED 明细/深度曲线/全量网格）。

## 准确性验证（核心验收）

测试命令：`npm test`（vitest，34 个用例）

1. **单 LED 照度 vs 点光源闭式解**：垂直下方与闭式解 `E=(Φ/K)/r²` 机器精度一致；偏离中心多点相对误差 < 1%
2. **500 组随机配置蒙特卡洛交叉验证**：独立参考实现（从四元数→世界位姿→标量公式完整重算）与引擎逐点误差全部 < 0.1%
3. **遮挡残余照度逐光源手算一致**：独立标量复算（朴素球方程判定 + 点光源公式）与引擎残余比例误差 < 0.5%，无遮挡/遮挡总量误差 < 1e-10
4. **射线-球**：500 条随机线段与独立二次方程参考实现 100% 一致；胶囊含退化球、球冠、侧偏用例
5. **通量守恒**：三种角分布数值积分误差 < 0.1%
6. **姿态四元数**：pitch/yaw/roll 往返误差 < 1e-9 度
7. 浏览器内「设置 → 运行计算自检」可现场复核上述关键项

> 标准遮挡体预设（头部球 r≈100mm、手部胶囊 r≈40mm）参照 IEC 60601-2-41 残余照度试验思路，尺寸均可调整；投标时请按所用标准版本核对具体口径。


## 关键约定

- 单位：角度度、距离米、光通量 lm、光强 cd、照度 lux
- 坐标系：Y 向上，术野平面为水平面（XZ）
- 灯头局部 -Y 为主轴；姿态 `q = Ry(yaw)·Rx(-pitch)·Ry(roll)`，pitch 规范域 [0°,90°]（负俯仰与 yaw+180° 主轴等价不可区分）
- 默认网格 81×81（1m 区域间距 12.5mm），可调 21–121
